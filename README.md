# Pococlip

AI video and image generator — pay per generation, no subscription.

**[pococlip.com](https://pococlip.com)**

## What it does

- **Text to video** — describe a shot, get a 5–15s clip (16:9, 9:16, 1:1, 4:3, 3:4, 21:9)
- **Image to video** — first frame, first + last frame, or up to 5 reference images
- **AI images** — 1K to 4K with reference images for consistency

## Models

Video: MiniMax H3 (1080P), Seedance 2.0, Seedance 2.0 Fast, Wan 3.0, Gemini Omni Flash
Images: GPT Image 2 / 2.5 Flare / 2.5 Sunburst, Nano Banana 2 / 2.1 / Pro, Grok Imagine

## Pricing

Credits are prepaid, one credit = $0.01 of list price.
- Video from **$0.072/s at 1080P** (5s ≈ $0.36)
- Images from **$0.01**
- Packs start at **$2**, credits never expire, failed generations refunded
